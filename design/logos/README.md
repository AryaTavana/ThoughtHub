# ThoughtHub logos

Use the `dark` variants on dark backgrounds and the `light` variants on light
backgrounds.

| Asset | Intended use |
| --- | --- |
| `thoughthub-icon-dark.svg` | Compact mark on dark backgrounds |
| `thoughthub-icon-light.svg` | Compact mark on light backgrounds |
| `thoughthub-horizontal-dark.svg` | Full horizontal logo on dark backgrounds |
| `thoughthub-horizontal-light.svg` | Full horizontal logo on light backgrounds |

Keep the SVG files as the source assets so they remain scalable for future UI,
social, and export uses.
